UniTex 隐私政策

生效日期：2026 年 10 月 8 日　·　开发者：马柏赢　·　联系邮箱：2056187056@qq.com

一句话概括：UniTex 默认在设备本地完成全部识别，不联网、不上传任何数据。 只有当你主动在「选项」里切换并配置了在线模型后，裁剪出的公式图片才会发送到 由你自己填写的那个服务地址。除此之外，本应用不与任何服务器通信。

一、会离开设备的数据

只有一种，且需要你主动开启：

  • 默认状态（本地模型）：零。图片、识别结果、全部设置都留在设备内。应用不会发起任何网络请求。
  • 你切换到「在线 API」之后：应用会把检测出的公式区域裁剪出的图片发送到你在「选项」里填写的接口地址，用于换取该区域的 LaTeX 代码。 发送的是裁剪后的小图，不是整张原图。
  • 你在「选项」里填写的接口地址、模型名称和 API Key，保存在本机应用私有目录。其中 API Key 会作为身份凭证随请求发送到你自己填写的那个服务地址——这是该服务识别你身份的方式，不发送则无法调用。
请注意：切换为在线模型后，图片将离开你的设备，并由你选择的第三方服务商处理。 该服务商如何处理与保存数据，适用其自身的隐私政策，本应用无法控制，也不对其负责。 如果图片含有你不希望外传的内容，请保持在默认的本地模型模式。

二、我们不做的事

  • 不收集设备标识符、位置、通讯录、短信、通话记录；
  • 没有账号体系，不需要注册或登录；
  • 没有广告，没有统计埋点，没有用户行为分析；
  • 没有集成任何第三方 SDK。

三、权限说明

  • ohos.permission.INTERNET（网络访问）：本应用申请的唯一个权限。 它只在「在线 API」模式下才真正使用；本地模型模式不会产生任何网络流量。
  • 相机与相册：通过系统的图片选择器与相机应用打开， 应用只能拿到你明确选中的那一张图片，无法访问相册中的其他内容，也不会在后台读取。
  • 手写输入：使用系统提供的手写板组件，笔迹仅用于生成待识别的图片， 不会离开设备（除非你又选择了在线模型模式）。

四、数据保存与删除

  • 设置项（含 API Key）、识别模型文件、内置示例图保存在应用私有目录中，其他应用无法读取。
  • 识别结果只存在于应用运行期间，不会写入任何持久文件（除非你主动复制或保存）。
  • 卸载本应用即可删除上述全部数据。你也可以随时在「选项」中清空 API Key。

五、未成年人

本应用不面向未成年人单独提供服务，也不会有意收集未成年人的个人信息。

六、本政策的更新

如果本政策发生变更，我们会在应用内更新本页面并修改顶部的生效日期。 继续使用本应用即表示你接受更新后的政策。
